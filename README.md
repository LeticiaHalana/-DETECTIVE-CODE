## 📜 O Cenário e a Missão

O objetivo da equipe é investigar as pistas deixadas no servidor e identificar o invasor através de 4 características fundamentais:
1. **COR DO TRAJE:** A cor da roupa que ele usava.
2. **COMANDO SQL:** A arma do crime utilizada na base de dados.
3. **CARGO / SETOR:** O cargo que ele ocupava na empresa.
4. **CÓDIGO NUMÉRICO:** O registo de ejeção gerado pelo algoritmo.

 Vocês têm **60 minutos** para concluir as investigações, juntar as pistas e ejetar o **NULL**!

## 🕵️‍♂️ 1. Investigador Git

### 📜 O Cenário
O hacker **NULL** apagou o ficheiro de logs das câmeras para esconder a sua identidade. No entanto, no Git, nada é verdadeiramente apagado se já tiver sido enviado num *commit*!

### 🗺️ Passo a Passo
1. Na página principal deste repositório, clique no botão **Commits** (ícone de relógio no topo da lista de ficheiros).
2. Explore os *commits* antigos realizados antes da sabotagem.
3. Localize o registo de câmeras e identifique a **COR DO TRAJE**.

---

## 🗄️ 2. Perito DBA (SQL)

### 📜 O Cenário
O hacker **NULL** invadiu a base de dados e inseriu erros de sintaxe nos comandos **DDL** (`CREATE TABLE`) e **DML** (`INSERT`, `UPDATE`) para bloquear o relatório de segurança.

### 🗺️ Passo a Passo
1. Faça o download ou copie o conteúdo do ficheiro [`log_corrompido.sql`](./log_corrompido.sql).
2. Abra o **MySQL Workbench** e cole o código numa nova janela de consulta (`Ctrl + T`).
3. Tente executar o script (`Ctrl + Shift + Enter`) e observe as mensagens de erro no painel inferior.
4. Depure os erros de sintaxe e execute o script corrigido para revelar o **COMANDO SQL**.

## 💻 3. Coder (C#)

### 📜 O Cenário
O **NULL** corrompeu a estrutura do laço de repetição `for` no ficheiro `GeradorCodigo.cs` para que o painel de segurança não consiga calcular a chave de ejeção.

### 🗺️ Passo a Passo
1. Copie o conteúdo do ficheiro [`GeradorCodigo.cs`](./GeradorCodigo.cs).
2. Abra o ficheiro no seu ambiente de desenvolvimento C# (Visual Studio, VS Code ou compilador online).
3. Corrija os erros de sintaxe e lógica no laço `for`.
4. Execute o programa e anote o **CÓDIGO NUMÉRICO** impresso na consola.

## 📋 4. Analista de Requisitos

### 📜 O Cenário
A documentação de requisitos foi rasgada antes do ataque[cite: 1]. Para descobrir qual era o **CARGO** do invasor, precisa de classificar as frases em **Requisitos Funcionais (RF)** e **Não Funcionais (RNF)**.

### 🗺️ Passo a Passo
1. Resolva o desafio das palavras cruzadas na folha impressa.
2. Descubra as 6 palavras técnicas associadas aos conceitos de RNF e Engenharia de Requisitos.
3. Monte o cargo organizando as **primeiras letras** de cada palavra na seguinte ordem:

$$\Large\text{Sequência: } 3 - 6 - 1 - 5 - 4 - 2$$
